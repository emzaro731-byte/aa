# AA Browser

Chrome-style Android browser built with Flutter.

## Features

- Google search and direct URL navigation
- Android WebView with JavaScript
- Back, forward, reload and home
- Multiple tabs
- Bookmarks
- Browsing history
- Dark/light mode
- HTTPS lock indicator
- Android back-button navigation
- GitHub Actions APK and AAB builds

The app uses Flutter's official webview_flutter package for Android WebView support.

## Build

Open GitHub Actions and run **Build Android Browser**. The workflow generates a release APK and AAB as downloadable artifacts.
